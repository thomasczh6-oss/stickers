# 上架清单（App Store / Google Play）

对照两个商店的审核要求，列出 App 和网站已经具备的页面、功能，以及上架前还要你来定或填写的东西。

## 已经做好的

| 要求 | 在哪里 |
| --- | --- |
| 应用内删除数据（Apple 5.1.1(v)、Google Play 账号/数据删除政策） | App：设置 → 删除我的所有数据；服务端 `DELETE /v1/me` |
| 网页版删除数据地址（Google Play 数据安全表单要填） | `https://<域名>/delete-data` |
| 把照片发给第三方 AI 前告知并征得同意（Apple 5.1.2(i)） | App 首次打开的引导页最后一屏；网页创建页底部的说明 |
| App 内能打开隐私政策和服务条款 | 设置 → 法律信息；引导页底部链接 |
| 隐私政策网址（两个商店都必填） | `https://<域名>/privacy`（已补充反馈、额度、删除数据的说明） |
| 支持网址（App Store 必填） | `https://<域名>/help`（常见问题 + 留言表单） |
| 联系客服、意见反馈 | App：设置 → 帮助；网页 `/help#contact`；服务端 `POST /v1/feedback`，存在 `feedback` 表 |
| 测试用的「服务器地址」不出现在正式包 | 只在开发版、`EXPO_PUBLIC_DEV_SETTINGS=1` 或连 http 服务器的测试包里显示 |
| 崩溃时不白屏 | App 根布局的 ErrorBoundary；网页 `app/error.tsx` |
| 免费额度（控制模型成本） | 每台设备每天 `FREE_PACKS_PER_DAY` 个（默认 2），失败的不算；用完显示额度页 / 价格页 |
| 德国、奥地利要求的 Impressum | `/imprint`，内容读 `IMPRINT_*` 环境变量 |
| 版本号、给 App 评分 | 设置 → 关于；评分在配了商店链接后出现 |

用户生成内容（发现页）的举报、屏蔽和社区规范由发现页那边一起做，Apple 1.2 要求的这几项上架前需要确认已合入。

## 上架前要你定或填写的

1. **付费方式**。现在 Pro 只显示「即将推出」，没有购买按钮（放一个点了没反应的购买按钮会被 Apple 2.1 拒）。确定方案后接 StoreKit / Google Play Billing（建议用 RevenueCat），并在设置里加「恢复购买」（Apple 要求）。
2. **账号登录**。现在不需要账号，用设备 ID。以后如果加第三方登录（Google 等），iOS 必须同时提供「通过 Apple 登录」，并且应用内要能删除账号。
3. **AI 服务商名称**。隐私政策目前写的是「我们的 AI 绘图服务」。Apple 建议写明具体是哪家，确认网关背后的服务商后补上。
4. **环境变量**：`NEXT_PUBLIC_CONTACT_EMAIL` / `EXPO_PUBLIC_CONTACT_EMAIL`（客服邮箱）、`EXPO_PUBLIC_SITE_URL`、商店链接、`IMPRINT_*`。
5. **法律文本审阅**。隐私政策和条款是英文草稿，上线前请律师过一遍；其他语言的用户会看到「仅提供英文」的提示。

## 商店后台要填的（不在代码里）

- **App 隐私标签（Apple）/ 数据安全（Google）**：收集照片（用于 App 功能，不关联身份，处理后删除）、用户内容（描述、贴纸）、设备 ID（App 功能）、可选的邮箱（客服）、崩溃和诊断日志。不用于追踪，不出售。
- **年龄分级**：生成式 AI + 用户上传照片，按问卷如实填写；条款写的是 13 岁以上（欧盟 16 岁）。
- **截图和预览视频**：iPhone 6.9 英寸、Android 手机，至少 3 张。
- **审核备注**：说明不需要登录；「添加到 WhatsApp」需要装了 WhatsApp 的真机；附一个做好的贴纸包链接方便审核员看。
- **WhatsApp 商标**：名称和截图里不要让人以为是 WhatsApp 官方出品（条款和页脚已写明无关联）。
